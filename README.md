# 债券基金筛选器

用天天基金（东方财富）的公开接口，按 **8 个指标加权打分** 筛选优秀的债券基金。后端零依赖（Node 18+），前端为 React（Vite）。提供「本地网页」和「命令行」两种用法。

## 快速开始

要求 Node >= 18。

```bash
npm install

# 方式一：本地网页（生产模式）
npm run build          # 构建 React 前端到 public/dist
node server.js         # 后端 + 托管前端，浏览器打开 http://localhost:3210

# 方式一（开发模式，热更新）：开两个终端
node server.js         # 终端1：后端 API（:3210）
npm run dev            # 终端2：前端 Vite（:5173，/api 自动代理到后端）

# 方式二：命令行，跑一次并导出 CSV/JSON
node cli.js                       # 默认筛选前 200 只债券基金
node cli.js --funds 000032,110027 # 指定基金代码
node cli.js --max 500             # 前 500 只
node cli.js --max 0               # 0 = 全量债券基金（耗时较长，首次约数分钟）
```

结果导出到 `data/output.csv` 和 `data/output.json`；网页端也有「导出 CSV / JSON」按钮。

## 评分的指标（按你的三档口径）

| 指标 | 权重 | 理想 | 可接受 | 需谨慎 | 数据来源 |
| --- | --- | --- | --- | --- | --- |
| 最大回撤 | ⭐⭐⭐⭐⭐ (5) | ≤ 0.5% | 0.5%~1.0% | > 1.0% | 累计净值近 3 年 |
| 回撤修复时间 | ⭐⭐⭐⭐⭐ (5) | ≤ 3 个月 | 3~6 个月 | > 6 个月 | 累计净值近 3 年 |
| 3 年年化收益 | ⭐⭐⭐⭐⭐ (5) | ≥ 3.5% | 3.0%~3.5% | < 3.0% | 累计净值 |
| 基金类型 | ⭐⭐⭐⭐⭐ (5) | 中短债/短债纯债 | 普通纯债 | 长债纯债 | 基金列表 + 名称 |
| 杠杆率 | ⭐⭐⭐⭐ (4) | ≤ 120% | 120%~130% | > 130% | 债券占净比（季报，近似） |
| 规模 | ⭐⭐⭐ (3) | 10~100 亿 | 5~200 亿 | < 1 亿 | 净资产 |
| 经理任职年限 | ⭐⭐⭐ (3) | ≥ 3 年 | 1~3 年 | < 1 年 | 现任经理 `workTime` |
| 综合费率 | ⭐⭐⭐ (3) | ≤ 0.5%/年 | 0.5%~0.8% | > 0.8% | 管理+托管+销售服务费 |

每个指标先换算成 0–100 分（理想段≈90 分以上、可接受段≈60~90、需谨慎段≈60 以下），再按权重加权求和得到综合分（0–100），缺失的指标自动从权重中剔除并重新归一。

> 久期（≤3 年 / 3~5 年 / >5 年）与信用质量（AAA 为主 / AAA+AA+ 为主 / 较多 AA 及以下）两个指标目前仍缺公开数据源——它们只写在基金季度报告里，公开净值接口拿不到，本版未纳入；阈值已备在 `src/config.js` 末尾，待接入季报数据后即可启用。

## 数据源（均为天天基金公开接口）

- 基金列表与细分类型：`fund.eastmoney.com/js/fundcode_search.js`
- 累计净值 / 净资产规模 / 现任经理：`fund.eastmoney.com/pingzhongdata/{代码}.js`
- 费率 / 成立日期 / 净资产：`fundf10.eastmoney.com/jjfl_{代码}.html`

原始响应会缓存到 `data/cache/`（列表 7 天、净值 15 天、费率 7 天），重复运行会很快。想强制刷新就删掉对应缓存文件。

## 候选池与缓存策略

为解决「全量太慢、非全量又漏基金」的矛盾，候选池做了三层处理：

- **类型白名单预筛**：默认只精算纯债类（中短债/短债、普通纯债、长债、债券指数），二级债/一级债/可转债/偏债混合/QDII 直接不进入候选池。可改 `src/config.js` 的 `INCLUDE_CATEGORIES`（并同步 `public/src/config.js` 的 `CATEGORIES`）。
- **A/C 份额去重**：同源份额（如「XX债券A / C / E」）风险画像几乎一致，只精算代表份额，其余记入「同源份额」列，请求量约减 40%。
- **净值缓存放宽 + 断点续跑**：净值缓存 15 天（回撤/年化对单日净值不敏感）；首次全量建库后，之后每天扫描都是本地计算、秒出。重跑时已缓存的直接读、只补抓没抓到的，天然断点续跑。

经过白名单 + 去重，全量候选从约 9600 只降到约 2900 只，首次全量建库十几分钟，之后秒级。

网页端结果**分页展示**（每页 50 条），筛选结果落盘到 `data/results/`，前端只按页加载、不整包驻留内存；排序、类别筛选、翻页都由后端分页接口处理，避免一次性渲染几千行卡顿。

## 配置

所有权重、打分阈值、类型偏好、回看窗口、并发数都在 `src/config.js`，改完直接生效。例如：

- 想把「类型」里的可转债/二级债偏好调高（更看重收益弹性），改 `TYPE_PREFERENCE`。
- 想改回撤/年化等打分曲线，改 `SCORE` 里的阈值表（`[数值, 得分]`，点间线性插值）。
- 想调整回看年限，改 `LOOKBACK`。

## 已知限制（重要）

1. **10 个指标里做了 8 个**。杠杆率用「债券占净比」近似（来自季报，会滞后一两个季度）；久期、信用质量仍只写在基金季度报告里，公开净值接口拿不到，未纳入。
2. **候选池没有在线预排序**。天天基金的 `rankhandler` 排名接口已失效（返回「无访问权限」），无法按收益预先排序，只能靠上面的白名单 + 去重缩小范围；默认按代码升序取前 N（`--max`），全量用 `--max 0`。
3. 偶发网络失败会被跳过（单只基金抓取会自动重试一次）。
4. 经理「任职年限」来自天天基金的 `workTime` 字段（累计口径），作为“是否经历过完整周期”的代理指标。
5. 数据为第三方公开接口、非官方 API，结构可能变动；结果仅供研究参考，**不构成任何投资建议**。

## 目录结构

```
bond-fund-screener/
├── server.js          # 后端：API + 托管 React 构建产物（零依赖 http）
├── cli.js             # 命令行入口
├── vite.config.js     # Vite 配置（root=public，dev 代理 /api）
├── src/               # 后端逻辑
│   ├── config.js      # 权重、阈值、类型偏好、抓取参数
│   ├── http.js        # 抓取 + 并发池 + 重试
│   ├── eastmoney.js   # 天天基金接口抓取与解析 + 缓存
│   ├── metrics.js     # 年化 / 最大回撤 / 回撤修复计算
│   ├── score.js       # 打分与加权
│   └── screen.js      # 筛选主流程 + CSV 导出
├── public/            # React 前端（Vite）
│   ├── index.html     # Vite 入口
│   └── src/           # 组件（App/Controls/Filters/FundTable/…）与样式
└── data/              # 缓存与导出结果（已加入 .gitignore）
```
